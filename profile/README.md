# ⚡ Swice Network

Bem-vindo à **Swice Network** — um servidor de Minecraft focado em performance, estabilidade e diversão!

## 🌐 Sobre

A Swice é um servidor de Minecraft que busca oferecer a melhor experiência para jogadores de todos os estilos. Nosso objetivo é criar uma comunidade forte e um ambiente estável para todos.

## 🎮 O que oferecemos

- **Alta performance** — Otimizações para garantir o melhor TPS
- **Modos únicos** — Gameplay personalizado e divertido
- **Comunidade ativa** — Sempre há alguém online para jogar junto
- **Eventos** — Participe de eventos e ganhe recompensas
