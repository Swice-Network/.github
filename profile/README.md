## Sobre

A **Swice Network** é um servidor de Minecraft que busca oferecer a melhor experiência para jogadores de todos os estilos. Foco em performance, comunidade forte e um ambiente estável para todos.

## Destaques

- ⚡ **Alta performance** — Otimizações para o melhor TPS
- 🎯 **Modos únicos** — Gameplay personalizado
- 🌊 **Comunidade ativa** — Jogadores online todo dia
- 🎉 **Eventos** — Participe e ganhe recompensas
